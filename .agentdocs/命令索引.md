# 命令索引

> 目的：给温室现场采集与后续回放用。  
> 现状说明：截至当前，**新导航框架尚未完成实机闭环验证**，也**不是你亲手跑通过的完整仿真链**。  
> 因此本文件优先服务于：**现场保底采集 -> 回放复现 -> 离线调参**，而不是把现场时间押在在线闭环上。

---

## 1. 当前主线实际入口

### 1.1 建图入口
```bash
roslaunch greenhouse_nav greenhouse_mapping.launch
```

> 说明：
> - 该入口会直接启动：`Mid360 驱动 + FAST-LIO 建图 + RViz`。
> - 如果要把地图落盘成 `scans.pcd`，仍需先检查 `src/FAST_LIO/config/mid360.yaml` 里的 `pcd_save_en` 是否打开。

### 1.2 导航入口
```bash
roslaunch greenhouse_nav greenhouse_navigation.launch
```

> 说明：
> - 该入口已经把温室导航主线默认配置固化好了：`FAST-LIO + localization + terrain_analysis + terrain_analysis_ext + FAR + CMU local + cmd_vel bridge + base serial + FAR RViz`。
> - 该命令默认等价于**正向模式**。
> - 若车头方向与传感器 / `body` 正好相反，请改用下面这个命令。

### 1.2.1 导航反向模式
```bash
roslaunch greenhouse_nav greenhouse_navigation_reverse.launch
```

> 说明：
> - 该模式只修正导航链里的 `body -> base_link` yaw = `pi`。
> - 建图命令 `greenhouse_mapping.launch` 不受影响。

### 1.3 兼容旧命令
```bash
roslaunch greenhouse_nav system_greenhouse.launch
```

> 说明：
> - 旧命令仍可用，但现在只是 `greenhouse_navigation.launch` 的兼容别名。
> - 下面再出现的长命令，都是 **bag 回放 / 无硬件 smoke / 开发调试** 用的内部命令，不是现场常规入口。

## 2. 现场第一轮：元信息快照

```bash
RUN_ID=$(date +%Y%m%d_%H%M%S)_greenhouse
META_DIR="$HOME/bags/$RUN_ID/meta"
mkdir -p "$META_DIR"

rostopic list > "$META_DIR/topics.txt"
rosnode list > "$META_DIR/nodes.txt"
rosparam list > "$META_DIR/params_list.txt"
rosparam dump "$META_DIR/params_dump.yaml"
```

如果你还想保存系统基础信息：

```bash
uname -a > "$META_DIR/uname.txt"
env | sort > "$META_DIR/env.txt"
df -h > "$META_DIR/disk_free.txt"
```

## 3. 现场第二轮：先找真实 topic 名

### 3.1 查雷达 / 相机 / TF
```bash
rostopic list | grep -Ei 'livox|mid360|imu|cloud|points|hik|camera|image|tf'
```

### 3.2 看消息类型
```bash
rostopic type <topic_name>
```

### 3.3 看频率
```bash
rostopic hz <topic_name>
```

### 3.4 看一帧消息
```bash
rostopic echo -n 1 <topic_name>
```

## 4. 现场第三轮：先录一个短包验证

> 先录 2~3 分钟，动作模板：
> - 静止 20~30 秒
> - 缓慢直行
> - 一次转弯
> - 停车
> - 再静止 5~10 秒

### 4.1 raw bag（必须）
先把下面占位符替换成现场真实 topic：

```bash
RAW_DIR="$HOME/bags/$RUN_ID/raw"
mkdir -p "$RAW_DIR"

rosbag record --split --duration=180 -O "$RAW_DIR/short_raw" \
  /tf \
  /tf_static \
  <MID360_POINT_TOPIC> \
  <MID360_IMU_TOPIC> \
  <HIK_IMAGE_TOPIC> \
  <HIK_CAMERA_INFO_TOPIC>
```

### 4.2 processed bag（强烈建议）
这些是当前主线默认 topic：

```bash
PROC_DIR="$HOME/bags/$RUN_ID/processed"
mkdir -p "$PROC_DIR"

rosbag record --split --duration=180 -O "$PROC_DIR/short_processed" \
  /tf \
  /tf_static \
  /state_estimation \
  /cloud_registered \
  /terrain_map \
  /terrain_map_ext \
  /goal_point \
  /way_point \
  /navigation_boundary \
  /robot_vgraph \
  /path \
  /cmd_vel_stamped \
  /cmd_vel \
  /speed
```

## 6. 每录完一个 bag 立刻检查

```bash
rosbag info <bag_file>.bag
```

快速确认：
- 时长是否正常
- topic 是否齐
- 文件大小是否异常小

如果要把 bag 信息存下来：

```bash
rosbag info <bag_file>.bag > "$META_DIR/$(basename <bag_file>.bag).info.txt"
```

## 7. 现场只做“只出 topic、不下发控制”的 smoke test

> 这一步不是必须；只有在 raw / processed 包都已经录到后，再做。

### 7.1 启动带 FAR 的系统，但不接底盘
```bash
roslaunch greenhouse_nav system_greenhouse_with_route_planner.launch \
  use_route_planner:=true \
  use_livox:=true \
  use_localization:=true \
  use_fastlio_mapping:=true \
  use_global_localization:=true \
  use_map_publisher:=true \
  use_adapter:=false \
  use_base_autonomy:=true \
  use_terrain_analysis:=true \
  use_terrain_analysis_ext:=true \
  use_base_serial:=false \
  localization_rviz:=false
```

### 7.2 观察关键 topic
```bash
rostopic hz /state_estimation
rostopic hz /cloud_registered
rostopic hz /terrain_map
rostopic hz /terrain_map_ext
rostopic hz /way_point
rostopic hz /navigation_boundary
rostopic hz /path
rostopic hz /cmd_vel_stamped
```

### 7.3 手动打一发目标点
```bash
rostopic pub -1 /goal_point geometry_msgs/PointStamped \
'{header: {frame_id: "map"}, point: {x: 3.0, y: 0.0, z: 0.0}}'
```

### 7.4 看 FAR 是否真有输出
```bash
rostopic echo -n 1 /way_point
rostopic echo -n 1 /navigation_boundary
rostopic echo -n 1 /robot_vgraph
rostopic echo -n 1 /path
```

> 如果这一步不通，**不要在现场深陷调参**。  
> 直接保住 bag，回去离线排。

## 8. 回来后的离线回放命令

## 8.1 先开 bag replay 时钟
```bash
rosparam set use_sim_time true
```

## 8.2 情况 A：bag 里已经有 `/state_estimation + /cloud_registered + /terrain_map + /terrain_map_ext`

这种情况下，优先复现 **FAR + CMU local**，不要再重复开在线定位和 terrain 节点：

```bash
roslaunch greenhouse_nav system_greenhouse_with_route_planner.launch \
  use_route_planner:=true \
  use_livox:=false \
  use_localization:=false \
  use_map_publisher:=false \
  use_adapter:=false \
  use_base_autonomy:=true \
  use_terrain_analysis:=false \
  use_terrain_analysis_ext:=false \
  use_base_serial:=false \
  localization_rviz:=false
```

然后回放：

```bash
rosbag play --clock <processed_bag>.bag
```

## 8.3 情况 B：bag 里只有 `/state_estimation + /cloud_registered`，没有 terrain topic

这种情况下，回放时在线重建 terrain：

```bash
roslaunch greenhouse_nav system_greenhouse_with_route_planner.launch \
  use_route_planner:=true \
  use_livox:=false \
  use_localization:=false \
  use_map_publisher:=false \
  use_adapter:=false \
  use_base_autonomy:=true \
  use_terrain_analysis:=true \
  use_terrain_analysis_ext:=true \
  use_base_serial:=false \
  localization_rviz:=false
```

然后回放：

```bash
rosbag play --clock <replay_bag>.bag
```

## 8.4 只测基础 CMU local，不开 FAR

```bash
roslaunch greenhouse_nav system_greenhouse_base.launch \
  use_livox:=false \
  use_localization:=false \
  use_map_publisher:=false \
  use_adapter:=false \
  use_base_autonomy:=true \
  use_terrain_analysis:=false \
  use_base_serial:=false \
  localization_rviz:=false
```

## 9. 推荐命名方式

```bash
YYYYMMDD_greenhouse_<route>_<speed>_<lighting>_<note>.bag
```

例如：

```bash
20260414_greenhouse_rowA_slow_day_staticstart.bag
20260414_greenhouse_rowB_turn_normal_dynhuman.bag
20260414_greenhouse_rowA_repeat_backlight.bag
```

## 10. 现场备注建议

每个 bag 至少记录：
- 起止位置
- 直行 / 转弯 / 掉头是否包含
- 是否有人/车动态干扰
- 是否有强反光 / 背光 / 暗区
- 传感器安装是否变动
- 这段包是否异常
