## 当前主线事实

- 下位机主工程是 `TR800_F407`，构建链为 `CMake + GCC + Ninja + OpenOCD`。
- 当前主控路径是 `UART4 SERIAL / IBUS RC / TR800_Runtime / A-B 双电机速度闭环`。
- 串口下行协议固定为 `11` 字节，上行协议固定为 `24` 字节，帧头 `0x7B`，帧尾 `0x7D`，异或校验。
- 当前串口控制包解析落点是 `UART4_IRQHandler()`，不要把 `USART3_IRQHandler()` 当成第一阶段主入口。
- 当前遥控主入口是 `USART2 + IBUS`，不是旧参考源码里的默认 SBUS 路径。
- 第一阶段只保留 `SERIAL` 和 `RC` 两种外部控制入口，`OFF` 只是内部无控制/保护状态。
- 当前电机只接入 A/B 两路，PWM 为 `PC6/PC7`，方向为 `PA2/PA3/PA4/PA5`。
- 当前编码器一阶段只关注 1/2 两路，对应 `TIM2/TIM3`。
- `TR800_OPEN_LOOP_PWM_TEST` 必须保持关闭，开环诊断只在明确排障时临时打开。
- `RELAY1/2/3` 不参与第一阶段主运动控制、模式选择或停机判断。

## 现场新增事实

- 2026-04-25 更换急停按钮后，当前软件下车辆已可动作。
- 这说明 MCU 输出链路、驱动使能链路和 A/B 电机链路在当前工况下可用。
- 急停信号现象为：正常释放约 `0V`，按下急停约 `3.3V`。
- 旧急停按钮或急停链路故障是本轮“车不动”的高概率原因。
- 编码器 2 仍是后续闭环稳定性风险，但不再作为“完全不动”的第一解释。

## 第一阶段优先级

1. 保持主线可构建、可烧录、可回滚，所有排障开关默认关闭。
2. 保持 `TR800_Runtime` 为唯一运行状态入口，停机原因统一进入 `fault_flags`。
3. 优先稳定 `SERIAL / RC -> Move_X/Y/Z -> Drive_Motor() -> PI -> Set_Pwm()` 主路径。
4. 暂不恢复 PS2、炮台、云台、未启用 CAN RX 和历史多车型泛化。
5. 实车验证前不继续扩大协议、引脚和模式范围。
