# RoboRTS-Firmware - 在线/离线与控制归零

来源：

- 仓库：`RoboMaster/RoboRTS-Firmware`
- 文件：`application/chassis/chassis_app.c`

## 摘录代码

```c
struct offline_obj chassis_offline_table[] =
{
    {SYSTEM_PROTECT, ENABLE, 0, 0, 0, 0, chassis_offline, chassis_online, NULL},
    {OFFLINE_DBUS, ENABLE, OFFLINE_ERROR_LEVEL, 0, 100, NULL, NULL, NULL, NULL},
    {OFFLINE_CONTROL_CMD, ENABLE, OFFLINE_WARNING_LEVEL, BEEP_DISABLE, 700,
        NULL, chassis_control_offline, NULL, chassis_control_online},
};

void chassis_control_offline(void)
{
    chassis_t p_chassis = get_chassis();
    chassis_set_acc(p_chassis, 0, 0, 0);
    chassis_set_speed(p_chassis, 0, 0, 0);
}
```

## 值得学的点

1. 在线/离线是显式状态，不是隐含在某个全局变量里。
2. 控制命令离线后明确归零。
3. 归零动作属于控制模块，而不是散落在多个 ISR 里。

## 对 TR800 的直接启发

- `serial alive`、`rc alive`、`enable`、`fault` 都应该最终汇入主环仲裁。
- 失联后的归零应当由主控制链路统一执行，而不是 ISR 顺手写零。

## 不要照搬的点

- 不要把整套 offline table 和 app_manage 机制搬进来。
- TR800 现在只需要学“显式状态 + 控制归零归属”，不需要学它的大型应用框架。
